<h3 align="center">🌿 About The Project 🌿</h3>

<br/>

** Zenvora ** is a minimalist, ambient web sanctuary built for developers, designers, and students who value deep focus, calm workflow, and digital well-being. 

Combining customizable Pomodoro cycles, soothing nature soundscapes, and an uncluttered dark interface, Zenvora helps you eliminate digital fatigue, enter a state of flow, and sustain high productivity throughout your day.

<br/>

---

<h3 align="center">⚡ Key Features ⚡</h3>

<br/>

- ⏱️ Customizable Focus Timer: Tailor work intervals, short breaks, and long resting cycles to fit your rhythm.
- 🎧 Ambient Audio Engine: Layer soothing soundscapes like gentle rain, forest breeze, and cafe ambience.
- 🧘 Distraction-Free Aesthetics: High-contrast, clean dark-mode visuals designed to minimize eye strain.
- 📊 Session Milestones: Keep track of completed focus sessions and maintain daily streaks.
- 📱 Zero Setup Required: Lightweight, fast, and responsive across all browser viewports.
